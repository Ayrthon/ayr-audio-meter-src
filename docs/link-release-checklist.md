# AYR Audio Link — release checklist

Link ships with its own in-app updater (see `crates/ayr-audio-link/src/updater.rs`)
that polls `https://api.github.com/repos/Ayrthon/ayr-audio-link/releases/latest`
on every startup. That public sidecar repo hosts installers + release notes
only; the source stays in the private `Ayrthon/audio-meter` workspace.

```
Ayrthon/audio-meter           ← PRIVATE, source for both Meter + Link
Ayrthon/ayr-audio-meter       ← PUBLIC, Meter installers + release notes
Ayrthon/ayr-audio-link        ← PUBLIC, Link installers + release notes   (NEW)
```

The two public repos are independent. You can cut a Link release without
touching the Meter and vice versa.

## One-time prerequisites

- Same Windows toolchain + Inno Setup 6 the Meter's checklist lists.
- `gh` CLI authenticated against an account with write access to
  `Ayrthon/ayr-audio-link`.
- Create the public sidecar repo once (`gh repo create Ayrthon/ayr-audio-link
  --public --description "Installers for AYR Audio Link, the free companion
  sender for AYR Audio Meter"`). Push a small README that mirrors the one in
  `Ayrthon/ayr-audio-meter` so the repo landing page has context.

## Every release

1. **Bump the version** in both places:
   - `crates/ayr-audio-link/Cargo.toml` → `version = "0.1.0"`
   - `installer/ayr-audio-link.iss` → `#define MyAppVersion "0.1.0"`

2. **Commit + push** on the private source repo's default branch:

   ```powershell
   git commit -am "link: release 0.1.0"
   git push
   ```

3. **Build the installer** from repo root. Output lands at
   `dist\AYR-Audio-Link-Setup-0.1.0.exe`:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\installer\build-link-installer.ps1
   ```

4. **Publish on the Link sidecar repo**. The tag must start with `v`:

   ```md
   ### Install

   Download **`AYR-Audio-Link-Setup-0.1.0.exe`** from the Assets below and run it. Approve the firewall prompt during install.

   > ℹ️ The `Source code` links are auto-generated by GitHub and contain only this repo's README — they're not the app. (GitHub does not let us hide them.)

   ### What changed

   Short changelog here. Rendered verbatim in the in-app update banner.
   ```

   ```powershell
   gh release create v0.1.0 `
     .\dist\AYR-Audio-Link-Setup-0.1.0.exe `
     --repo Ayrthon/ayr-audio-link `
     --target main `
     --title "0.1.0" `
     --notes-file .\link-release-notes.md
   ```

5. **Smoke test on two PCs:**
   - Install Link on PC A. Start broadcasting with any input device.
   - On PC B, open the Meter 2.x. Open the device dropdown. Within a few
     seconds the `[NET]` entry should appear.
   - Pick the `[NET]` entry, press Start. Speak / play audio on PC A. Levels
     should move on PC B within ~100 ms.
   - Close Link on PC A. The `[NET]` entry on PC B should disappear from the
     dropdown within ~30 s (mDNS TTL).
   - Reinstall an older Link build on PC A, then run the new installer. The
     updater banner should show "Update available" within seconds of launch.

## Troubleshooting

- **Meter doesn't see the sender.** Check the firewall rule was actually
  added (`netsh advfirewall firewall show rule name="AYR Audio Link"`). If
  the rule is missing — which happens when the user unticked the firewall
  task during install — re-run the installer or add the rule manually.
- **Updater banner never appears.** The Link updater logs to `env_logger`'s
  default sink; set `RUST_LOG=info` and relaunch from a terminal to see the
  `updater: checking ...` / `updater: up to date` lines.
- **mDNS dead on the LAN.** Some mesh routers rebroadcast mDNS with stale
  caches; restart the router. Corporate networks may block UDP 5353
  entirely, in which case Link doesn't work there — document it, don't try
  to tunnel around it.
